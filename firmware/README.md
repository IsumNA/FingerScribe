# Sleeve firmware

`fingerscribe_ble/fingerscribe_ble.ino`: firmware v9 for the Seeed XIAO nRF52840 Sense. It handles 100 Hz IMU streaming, on-chip tap detection at 833 Hz, hold-to-talk 8 kHz ADPCM audio, pocket-mode storage in flash, battery reporting and BLE (Nordic UART).

The parts list, wiring, flashing steps and the full Bluetooth protocol are in [docs/HARDWARE.md](../docs/HARDWARE.md).
